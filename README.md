# Компьютерные сети и системы

Лабораторные работы по предмету "Компьютерные сети и системы". БГТУ, 2 курс.

## Что внутри

- laboratory_1 — клиент-серверное приложение на C++
- laboratory_2 — клиент-серверное приложение (client / server)
- laboratory_3 — клиент-серверное приложение (несколько клиентов и серверов)
- laboratory_4 — модель сети в Cisco Packet Tracer (.pkt)
- laboratory_5 — модель сети в Cisco Packet Tracer (.pkt)

## Про работы

Лабораторные 1–3 — программы на C++ (Visual Studio) для работы с сетью через сокеты. Лабораторные 4–5 — моделирование сетей в Cisco Packet Tracer.
